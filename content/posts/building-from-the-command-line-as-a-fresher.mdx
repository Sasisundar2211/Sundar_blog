I cannot write a standalone Python backend from scratch without AI yet.

I am a 21-year-old final-year AIML student at PSCMR College of Engineering and Technology (Class of 2027), with zero prior corporate experience.

Instead of pretending to be a senior engineer, I built a terminal-first workflow that lets me ship real software while studying fundamentals every day:

-> Voice Specs via Wispr Flow: I dictate product logic and edge cases at 250 WPM instead of typing slow prompts
-> Persistent Rules via `CLAUDE.md`: Every repository stores my stack rules, file structure, and formatting constraints so the agent never starts cold
-> Terminal Execution via Claude Code CLI: I let the agent scaffold Next.js routes, Supabase queries, and webhooks while I inspect diffs, run `git` commits, and test endpoints locally

The human makes the architectural decisions. AI handles the execution.

Right now, I split my week between finishing the final 30% of Finance PSU Guide, preparing for IELTS ahead of a Fall 2027 Master's in the USA, and practicing Python and DSA without autocomplete.

Syntax is becoming a commodity. Knowing what to build, how to verify it in the terminal, and where it breaks is the real skill.
